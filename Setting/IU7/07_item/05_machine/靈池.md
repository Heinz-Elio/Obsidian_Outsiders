# 靈池

Soul Pool

---

---
## 簡介

由鳥人研發，用於保存族人「靈魂」的裝置，外表為高約1米，直徑約30公分的金屬圓柱體。其儲存的法力早已自然消散殆盡，在[[弗拉基米爾．萊文斯基]]與[[天城博敏]]進入神殿時已不再工作，後被兩人運回遠古生物及文明研究所。由於弗拉基米爾需要誘騙康士坦絲合作對付米迦勒，所以將經過[[去特徵化]]處理的杜溫法力注入其中，偽裝成仍在運作的古代遺物，以證明自己擁有對抗米迦勒的力量。

原本設計的常規載荷為約1000人份（以人型阿奎斯托為標準）的超高壓縮法力，因為嚴重劣化，載荷只剩下5%左右，而且重灌後持續明顯滲漏。
