## 簡介

[[阿奎斯托]]在陸地上建立的秘密結社，標誌為七芒星。組織銘言為「Superiora de inferioribus, inferiora de superioribus（英語：That which is above is from that which is below, and that which is below is from that which is above，中文：上自於下，下自於上）」，不使用[[阿奎斯托語]]是為了避免引起注意。核心成員是一群學者。深海之星的學者曾向現代人類傳授知識與技術，並在他們面前施展法術，這些人後來以希伯來語刻下黃金石碑（The Golden Tablet，被過去的鍊金術士視為鍊金術基石的碑文），並以此銘言為開首。這段話後來被翻譯為「Quod est superius est sicut quod inferius, et quod inferius est sicut quod est superius（英語：That which is above is like to that which is below, and that which is below is like to that which is above，中文：如其在上，如其在下）」，雖然仍可解讀為暗示阿奎斯托的存在，但一般被解讀為「小宇宙（微觀系統）是大宇宙（宏觀系統）的投影」此一普遍存在於各種文化裡的哲學概念。

性質上是一個交流互助平台，在世界各地設有聯絡辦公室，任何有阿奎斯托血統的人都可以登記加入。由於阿奎斯托壽命普遍較人類長，經常需要透過深海之星獲取假身份，故所有成員皆透過編號與法力散逸模式區分，成員使用的假身份與聯繫方式都依賴自行更新，因此成員忘記更新訊息導致紀錄滯後的情況屢見不鮮，更有甚者，這些人基於各種原因沒有告知後代深海之星的事，導致死後沒人幫他注銷會籍，成為深海之星的幽靈成員，可能幾十年後才有後代發現並處理。過去深海之星都是定期靠人手查核，近年為了進一步減少幽靈成員開始要求成員每年更新會籍及資訊，但受限於紙本紀錄與資料不互通，檔案紀錄還是頗為混亂。歐洲本部雖進一步推行成員資料電子化，並順勢開設網站、營運討論區，促進交流與資訊流通，但還處於剛起步的混亂期，其他分部則尚未跟進。

要求成員遵守保密協議，不得隨意向人類透露深海之星的存在，並需盡力協助深海之星為保密而作出之行動。

深海之星北美分部並非由本部建立，而是由隨著歐洲殖民美洲的步伐前往北美拓荒的資本家與在本部失勢的成員聯手建立，他們強行納入當地人建立自己的勢力，在發展起來後強迫本部承認其為分部，因此本部對北美分部無管制力，雙方合作亦僅限於舉辦研討會、商業活動，相互資訊不流通，成員會籍不共通亦不能轉移。
