# 靈池

前情：諾愛爾、可伶、尼歌娜需要前往A點，A點位置偏遠，只能開車去，由於路線選擇有限，預計會有埋伏，需提高火力配置

VS: 諾愛爾、可伶、尼歌娜

場地：郊區公路，四周是自然森林高地

裝備：
- [[M4A 60毫米壓縮法力砲]] * 4（1支臨時生產）
- [[KS SSG69E 複合狙擊步槍]] * 2
- [[M5 法力步槍]] * 2

載具：
- Toyota Land Cruiser 100，車頂改裝武器平台

特性：體型巨大，表層覆滿從靈池容器溢出的不受控法力，宛如大型火球，只會以法力進行直線攻擊，移動速度不快，但行動完全不受地型限制。核心雖對外溢法力有一定約束，但效果很弱。

攻略難點：
- 尼歌娜的壓縮法力砲無法突破表層法力
- 靈池太大還會移動，諾愛爾難以建立干擾法陣消解表層法力使核心暴露
- 不知道法力層到底有多厚、法力源頭在甚麼位置
- 法力投射出去後無法再導引，與靈池的極限安全距離高於直接控制法力攻擊的極限，必須製造近距離攻擊的機會，但近距離攻擊需要直面失控法力，風險極高

遭遇試探階段：
- 三人發現公路前方被投放巨型敵人，表面能量太高無法靠近
- 可伶駛下公路，保持距離觀察
- 謹慎靠近時發現靈池正在隨機向周圍發射法力束
- 靈池攻擊不受物理環境阻礙，速度快能量高，諾愛爾都幾乎擋不住，只能在車上繞圈機動
- 換成尼歌娜開車，諾愛爾以狙擊槍、可伶以壓縮法力砲在車頂攻擊，測試有效傷害類型，兩者皆無效

策略：
- 尼歌娜以砲擊引導靈池的移動
- 可伶載著諾愛爾在周邊部署壓縮法力砲，裝填干擾法力，目標不是完全覆蓋靈池，而是從不同角度打穿靈池的法力層，使核心暴露
- 可伶需要尋找適合快速接近靈池的高處，在法力層局部瓦解時衝入擊破核心
- 需要確認法力層厚度、核心位置、核心防禦強度，必須保留至少能夠執行三次完整流程的法力
- 諾愛爾需要給可伶施加多層高強度防禦法術吸收穿過法力層時的能量，尼歌娜需要在下方提供緩衝層

結束：
- 共測試三次
	- 第一次確定法力層厚度及確認核心位置，可伶根據位置決定起步點
	- 第二次核心暴露，但可伶進攻路線受到靈池的砲擊阻擋，尼歌娜砲擊核心牽制掩護可伶後退，可伶手臂側面小面積燒傷
	- 第三次成功擊中核心，但核心強度超過預期，可伶判斷發動攻擊時需要更靠近核心

- 諾愛爾根據核心位置及可伶的進攻路線，重新計算射擊角度
- 尼歌娜持續引導靈池
- 諾愛爾倒數射擊，可伶起跑，從高處躍下，落在法力層的空洞位置，對核心近距離發射雷光
- 尼歌娜以法術生成緩衝層接住可伶，並迅速撤離，諾愛爾開車前來接載
- 可伶短暫與法力層接觸導致燒傷；尼歌娜與諾愛爾輕度法力透支，三人皆體力見底
- 核心在法力風暴中徹底破壞，法力風暴在一段時間後停止，該區游離法力濃度暫時上升

重點：展現快速反應、制定測試敵人特性方案、執行能力、團隊配合
