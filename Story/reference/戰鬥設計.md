# [[靈池]]

前情：諾愛爾、可伶、尼歌娜需要前往A點，A點位置偏遠，只能開車去，由於路線選擇有限，預計會有埋伏，需提高火力配置

VS: 諾愛爾、可伶、尼歌娜

場地：郊區公路，四周是自然森林及高地，靈池位於公路，攻擊範圍完全覆蓋周邊可行駛地形，無法繞過

裝備：
- [[M4A 60毫米壓縮法力砲]] * 4（1支臨時生產）
- [[KS SSG69E 複合狙擊步槍]] * 2
- [[M5 法力步槍]] * 2
- [[60毫米蝕刻彈]] * 5排
- 60毫米干擾蝕刻彈（定時自爆，範圍半徑0.23米，只能用諾愛爾的法力容器發射） * 3排

載具：
- Toyota Land Cruiser 100，車頂改裝武器平台

特性：體型巨大，表層覆滿從靈池容器溢出的不受控法力，宛如大型火球，表面隨機噴射法力束，移動速度不快，但行動完全不受地型限制。核心雖對外溢法力有一定約束，但效果很弱。

攻略難點：
- 約有60人份的游離法力，壓縮至約1人份體積，超過劣化後約50人份正常載荷，比正常更不穩定，已洩漏4-5成，洩漏法力膨脹到18-22米高，攻擊範圍10-20米
- 實體蝕刻彈必須打中核心才可能有用，若用M4A直接投射壓縮法力，會先撞上具質量的表層法力，在外層提前激發，無法觸及核心
- 靈池太大還會移動，諾愛爾難以建立干擾法陣消解表層法力使核心暴露
- 不知道攻擊距離極限、法力層到底有多厚、法力源頭在甚麼位置、有多大、甚麼材質、防禦強度、有沒有特殊法術機制
- 即使能直擊核心，蝕刻彈威力不足以破壞核心，需要高能壓縮法力引爆核心內壓縮法力，法力投射出去後無法再導引容易打偏，直接導引法力攻擊需要專注操作，但50米外法力擴散程度較高，能量密度不足以造成有效傷害，必須近距離集中攻擊，但這需要直面高能法力粒子爆炸，風險極高

遭遇試探階段：
- 三人發現前方（5公里）有一團異常光霧，接近（2公里）發現路上被投放巨型敵人，且表面能量極高無法靠近
- 謹慎靠近（300米）時發現靈池正在隨機向周圍發射法力束
- 可伶駛下公路，保持距離觀察，確認無法繞行
- 進一步靠近估算攻擊範圍
- 靈池攻擊不受物理環境阻礙，速度快能量高，諾愛爾都幾乎擋不住，可伶迅速駛離回安全距離
- 尼歌娜以狙擊槍、M4A在車頂攻擊，測試有效傷害類型，兩者皆無效

策略：
- 尼歌娜在周邊200-250米部署三門裝填干擾蝕刻彈的M4A，諾愛爾計算測試射擊的角度，目標不是完全覆蓋靈池，而是從不同角度打穿靈池的法力層，使核心暴露
- 可伶尋找適合快速接近靈池的高地，在法力層局部瓦解時衝入，以晶核長槍發射壓縮法力引爆核心
- 確認核心位置、可伶的進攻路線、法力填補空洞速度，據此計算清空沿路法力並維持路線淨空需要的干擾彈落點與發射時機
- 必須保留至少執行三次完整流程的法力
- 尼歌娜負責裝填M4A、外圍砲擊支援（物理殺傷）
- 諾愛爾給可伶施加多層高強度防禦法術吸收穿過法力層時的能量

結束：
- 共測試三次
	- 第一次確認靈池各項關鍵參數，尼歌娜判斷實彈傷害不足，可伶根據核心大小、位置決定起步點
	- 第二次核心暴露，但可伶進攻路線受到靈池的砲擊阻擋，諾愛爾緊急投射法力干擾，尼歌娜在外圍砲擊核心牽制，掩護可伶後退，可伶手臂側面小面積燒傷
	- 第三次可伶成功擊中核心，但核心強度超過預期，可伶判斷發動攻擊時需要更靠近核心

- 諾愛爾根據核心位置及可伶的進攻路線，重新計算射擊角度並遙控修改
- 尼歌娜完成重新裝填後倒數射擊，可伶起跑，從高處起跳，穿過法力層空洞，對核心近距離發射壓縮法力
	- 85–95米起跑，起跳高度16-17米（含強化加成），起跳點至攻擊點3–4米，最終距離核心 3–5米
	- 輕微坡度，有跑動空間允許閃避法力束
	- 干擾只能維持約18秒，16秒內起跳，2秒滯空期內瞄準並射擊
- 可伶在另一側落地，諾愛爾開車接應可伶迅速撤離
- 可伶短暫與法力層接觸導致燒傷，法力有餘，戰後自行治療（兩發雷光、幾次緊急防禦法術、兩次強化）
- 諾愛爾輕度法力透支（大量使用防禦法術，支援時投射了幾次干擾法力）
- 尼歌娜回收武器及接手開車
- 核心被法力爆炸徹底破壞，法力爆炸幾乎波及三人

重點：展現快速反應、制定測試敵人特性方案、資源分配、彈道計算、執行能力、團隊配合
