# 線索 DSL 寫法

每篇 `線索-DSL-*.md` 只需維護一個 ```clues 區塊，圖與 Canvas 都由腳本重生：

- `python scripts/clues_to_graphviz.py <筆記>`：重生靜態圖
- `python scripts/clues_to_canvas.py <筆記>`：重生同名 `.canvas`（可拖曳、縮放）

## 指令

| 寫法 | 作用 |
|---|---|
| `標題: …` | 圖標題 |
| `方向: LR` | 由左至右排版；預設由上至下 |
| `時序: a, b, c` | 時點先後；`@時點` 相同的節點排在同一層 |
| `輸出: svg` | 圖另存成 `<筆記名>.svg` 並以 `![[…]]` 嵌入筆記；預設是把 DOT 寫在筆記內 |

## 群組

`# 群組`，`##` 為巢狀。群組標題也能當連線端點（箭頭接到群組框），例如 `遇害 -導致-> 兇手是誰？`。群組標題不要和短鍵同名。

## 節點

```text
類型 短鍵 : 細節 = 別名 @時點 #狀態
```

- 只有 `類型` 與 `短鍵` 必填；`: 細節` 的冒號是半形，且**前後要有空格**（避免和 `19:00`、全形「：」混淆）。
- 圖上只顯示短鍵；細節出現在 Canvas 卡片和 SVG 滑鼠提示。
- 連線只寫短鍵，所以改細節不會弄斷連線。短鍵在同一篇內必須唯一。
- 不寫細節時，短鍵就是全文（舊寫法照樣可用）。

類型：證據／事件／實體／假設／未決／矛盾／未分類。填色與形狀代表類型。

狀態：已確認／預定／推論／補丁／採信／排除。邊框粗細與虛實代表狀態，省略時依類型取預設值。`#採信` 是雙框，`#排除` 會變灰但保留在圖上（留下排除過程）。

## 連線

```text
A -> B -> C                 鏈：A→B、B→C
A -支持-> B | C             一對多
A | B -> C                  多對一
A -> B | C -> D             A→B、A→C、B→D、C→D
```

關係：支持／導致／推導／矛盾／時序／屬於。省略時畫成「關係未定」的灰虛線；其他文字會照原樣印成連線標籤。

連線引用了未定義的短鍵時，會自動補成「未決」節點並列入稽核訊息——這通常代表打錯字。

## 調查結構（建議）

```text
# 事件                 時間線，用 -時序-> 串起
# 兇手是誰？            一個問題一個群組，裡面放證據與候選推論
# 真相                 放在旁邊，只放連到真相筆記的節點

遇害 -導致-> 兇手是誰？        事件開出調查問題
財物消失 -支持-> 劫殺          證據 -支持/矛盾-> 推論
假秘書所送 -推導-> 兇手是假秘書  推論 -推導-> 推論
```

稽核會提醒：

- 證據直接連到證據（`時序`、`屬於` 除外）——中間通常少了一個推論。
- 證據、事件、假設、矛盾沒有任何連線。
- 假設沒有任何進來的連線（`#排除` 除外）——代表沒有依據。
- 連線缺少端點（如 `A -推導->` 寫到一半）。
- 節點連到自己所在的群組。
